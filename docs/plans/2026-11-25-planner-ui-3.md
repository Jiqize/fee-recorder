## 定下的取舍

- 右页 = 正文列 + 176pt 页边贴纸栏（菲比涂鸦、原话签、待办便利贴、录音铅笔、分享 / 导出印章）。右页窄于 680pt 时贴纸栏收起：待办回正文、印章回右下角（第二轮的样子）。取代旧的 262pt 页边栏。
- 纪要排版只改 `document` 模式（主窗口），实时纪要窗的排版不跟着变。
- 动效都看系统「减少动态效果」：打开时直接切换。
- 实时纪要窗只把标题栏换成皮面书脊、「此刻」换黄纸；正文仍不画横线、不歪、不放菲比；仍是不抢焦点、`sharingType = .none`。
- 设置、引导改成皮面手帐两页（目录页 / 第一页），右边分隔页；软木板不再用在这两处。
