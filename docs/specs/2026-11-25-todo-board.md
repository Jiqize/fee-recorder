# 待办大改：跨会议待办板 · Spec

状态：已确认（2026-11-25）
相关：DESIGN.md（纸上手记）、样稿 `docs/design/mockups/todo-board.html`

## 背景与目标

现在每场会议的纪要里有一组 AI 提取的待办（文字、负责人、出处时间），只能在那场会议里看、改文字，没有「做没做完」，也不能自己加；会开多了，待办散在各场会议里，没人跟进。

目标：
1. 待办能**跟进**：有状态（没开始 / 进行中 / 做完了）、截止日、星标，能自己加。
2. 所有会议的待办汇在**一块待办板**上，默认先看「我的」，能顺着点回它是在哪场会议、哪句话里说的。
3. 不丢东西：AI 重新整理纪要时，你勾过的、改过的、自己加的待办都在。

用户已定（2026-11-25）：做跨会议待办板；字段要「自己加 / 截止日 / 进行中 / 星标」；暂不同步到外部工具；「我的」优先。

## 关键行为

### 一条待办

- 有：文字、负责人（你 / 某个说话人名字 / 没人认领）、来源会议与出处时间（AI 提取的才有）、状态、截止日（可空）、星标（开 / 关）、谁写的（AI / 你）。
- 状态三种：**没开始** ☐、**进行中** ▸（红铅笔）、**做完了** ☑（绿勾，文字划线变浅）。点方框：没开始 → 做完了；做完了 → 没开始；「进行中」在右键菜单和待办详情里切。
- 打勾时铅笔勾 0.2 秒画出来；系统「减少动态效果」打开时直接出现。
- 截止日：
  - AI 整理纪要时，听到明确的时间（「周五前」「下周三」「3 月 6 日」「月底」）就按**会议当天**换算成日期填上；听不出就空着。
  - 你可以改、清空；手改过的截止日 AI 不再动。
  - 显示：今天 / 明天 / 周几（本周内）/「3 月 6 日」；过期的用 `error` 色写「逾期 N 天」。
- 星标：一颗手画星；星标的在各分组里排最前。
- 自己加的待办：在某场会议的待办便利贴上「＋ 加一条」，或在待办板上「＋ 加一条」（不属于任何会议，来源写「手记」）；显示成黄纸条蓝字（DESIGN.md 用户便签）；负责人默认「你」。
- 改文字、负责人、截止日：点一下原地改（沿用纪要编辑的手感：下划线输入框，⏎ 保存、esc 取消、清空文字即删除）。
- 删除：AI 提取的待办删掉后，同一场会议 AI 再整理时不再加回来；自己加的直接删。

### AI 重新整理时不丢东西

- 会议进行中纪要会反复重写。规则：
  - 你**碰过**的待办（改过状态、文字、负责人、截止日、星标）原样保留，AI 不改它；
  - 你自己加的待办原样保留；
  - AI 提取、你没碰过的：按新一版纪要更新（文字可能变、可能消失、可能新增）；
  - 你删掉的 AI 待办不再出现。
- 会后「重新生成纪要」「重新转写」也遵守同样规则。
- 怎么认「同一件事」（AI 会换措辞、换语言、改负责人）：先看文字；文字不同时，看出处时间（±1 秒）和负责人都相同；还认不到时，如果那一刻只有这一条候选（保留的 / 删掉的一边只有一条、新回复里也只有一条），负责人变了也算同一件事。同一句里有多条候选时仍按负责人区分，一条只认一条。（2026-11-25 用户决定放宽：会后完整版常把「未认领」改成某个人，原规则会多出一条重复。）

### 待办板（主窗口）

- 入口：主窗口左栏软木板最上面，搜索框下方钉一张「待办」索引卡，写着「我的 N 条没做完」（有逾期时加红字「其中 M 条逾期」）；点开后右侧笔记页换成待办板。会议卡片照旧在下面。
- 页面是一整张横线纸（同纪要页排版：角色栏 + 正文 + 行尾）。
- 页眉：菲比（有逾期时用「出了点问题」那张，全部做完用「写好了」那张，否则「在写」）+ 标题「待办」+ 一行统计「没做完 N · 逾期 M · 本周到期 K」。
- 两个标签（纸上的字，同纪要 / 文字记录）：**我的**（默认）、**别人的**。
  - 我的 = 负责人是「你」+ 没人认领的（没人认领的标灰字「未认领」）。
  - 别人的 = 负责人是其他人；按人分组，每组标题是人名 + 说话人头像。
- 「我的」分组（小节标题 + 波浪线），从上到下：**逾期**、**今天**、**这周**、**以后**、**没有截止日**、**做完了**（默认折叠，显示「做完了 N 条 ›」，只列最近 30 天）。每组内：星标在前，再按截止日、再按出处时间。
- 每条一行：角色栏是方框 / ▸ / ☑；正文是待办文字 + 灰字「· 负责人」（别人的分组里不重复人名）；行尾是截止日和来源会议名（红铅笔小字，可点：打开那场会议的文字记录并跳到那句话）；星标在行尾最右。
- 筛选：页眉右边「按会议」「按人」两个虚线字，点开下拉选；选中后标题下出现一张小牛皮纸条「只看：春季上新计划会 ×」。
- 页脚沿用纸面页脚：状态行「✓ 都做完了」或「* 还有 N 条」，搜索行「› 在待办里找…」只搜待办文字。

### 会议里的待办（纪要页、页边栏、实时纪要窗）

- 纪要页页边栏的粉色便利贴、窄窗时正文里的「待办」小节：显示状态 / 截止日 / 星标，能直接勾、能「＋ 加一条」。
- 实时纪要窗：待办能勾（只有方框，不显示星标和截止日编辑），样式仍是最低装饰。
- 页边栏「本场」统计的「待办」一行改成「待办 2/3」（做完 / 总数）。

### 菜单栏面板

- 「显示方式」下面加一行：「待办：今天到期 N 条 · 逾期 M 条 ›」，点开主窗口的待办板；都没有时这一行不显示。

### 导出与分享

- Markdown：`- [ ]` / `- [x]`，进行中写 `- [ ] ▸`，截止日写在行尾「（截止 3 月 6 日）」，星标写 `★`。
- Word、复制全文：☐ / ▸ / ☑ + 同样的截止日、星标写法。
- 分享链接：只带文字和负责人（同现在），不带状态（分享页属于上游网站，不在本 fork 范围）。

### 兼容

- 旧会议记录照常打开：没有状态的待办都算「没开始」，没有截止日。
- 记录文件里新增的字段都是可选的；不改已有字段的含义。

## Out of Scope

- 同步到 Apple 提醒事项、Feebee Board、钉钉等外部工具。
- 到期提醒通知、重复待办、子任务、附件。
- 待办板的拖拽排序、看板列视图。
- Windows / Linux / Android / iOS 和分享网页。
- 多人协作（别人在自己电脑上勾的状态同步过来）。

## 验收标准

1. 一场有 2 条 AI 待办的会议：在页边栏便利贴上勾掉 1 条 → 待办板「我的 › 做完了」里有它，统计「待办 1/2」。
2. 会议进行中勾掉 1 条、改 1 条文字、加 1 条自己的 → 之后纪要自动重写 3 次，这 3 条状态和文字都没变。
3. 删掉一条 AI 待办 → 点「重新生成纪要」后它没回来。
4. 会议当天是 2026-11-20（周五），说「下周三前给大家看」→ 这条截止日是 2026-11-25；把系统日期过了这天 → 它出现在「逾期」组，红字「逾期 N 天」。
5. 待办板点一条的来源会议名 → 主窗口打开那场会议的文字记录，跳到出处那句。
6. 「我的」只含负责人是「你」和未认领的；「别人的」按人分组。
7. 星标的排在所在分组最前。
8. 「做完了」默认折叠，只列最近 30 天的。
9. 菜单栏面板在有今天到期 / 逾期时显示那一行，点开到待办板。
10. Markdown 导出里状态、截止日、星标的写法符合上面的规定。
11. 打开一份旧版记录（没有新字段）不报错，待办都是「没开始」。
12. 中文、英文界面都没有截断和重叠；系统「减少动态效果」时打勾没有动画。
13. `scripts/test.sh` 通过；新增的状态合并、截止日换算、分组排序都有单元测试。
